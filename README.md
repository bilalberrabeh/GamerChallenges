Gamer Challenges 👾🥇

This project is my end-of-training web development assignment. It consists of a fully customizable and interactive platform designed for gamers who want to create, complete, and share video-game challenges.

The website allows users to propose challenges for any game, upload videos of their attempts, and engage with the community through likes and rankings. Each challenge submission can receive likes from other users, and the player whose video earns the most likes automatically reaches the top of the podium.

The platform focuses on a smooth user experience, dynamic interactions, and an engaging community-driven environment. It is built with scalability in mind, making it easy to evolve with new features such as user profiles, categories, or advanced ranking systems.
